# Androidnativclareza

Repositório destino para a migração do app web "Clareza Financeira" para Android nativo (Kotlin + Jetpack Compose).

Este repositório é gerado automaticamente como _initial commit_ para habilitar a criação de branches e começarmos a migração.

Branch padrão para migração: `android-native-migration`.

Instruções:
- Vou criar uma branch `android-native-migration` e adicionar o projeto Android em Kotlin + Jetpack Compose nesta branch.
- Um workflow para gerar APK debug pode ser adicionado posteriormente.

Autor: migração automática iniciada por assistência.
